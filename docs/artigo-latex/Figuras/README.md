# Imagens do artigo

Adicione nesta pasta as capturas abaixo, mantendo os nomes indicados:

- `cenario-campus.png`: visão do cenário inspirado na URI Campus II.
- `sistema-quiz.png`: tela de uma pergunta com as alternativas.
- `interface-jogo.png`: jogabilidade mostrando tempo, livros e erros.
- `inimigo.png`: imagem do inimigo dentro do cenário.

Enquanto uma imagem não existir, o artigo exibirá uma caixa reservando seu
espaço. Os formatos podem ser alterados no arquivo `.tex`, caso as capturas
sejam salvas como `.jpg`.
